Opción A: Instalar PWA en Teléfono

Funciona como app nativa sin tiendas de aplicaciones.

Android (Chrome)

Pulsa el botón **"Instalar App"** arriba o abre el menú de opciones (⋮) y elige **"Añadir a la pantalla de inicio"**.

iPhone / iPad (Safari)

Toca el botón **Compartir** de Safari (cuadrado con flecha hacia arriba) y selecciona **"Añadir a la pantalla de inicio"**.

Opción B: Publicar Gratis en Web

1

2

GitHub Pages: Sube el archivo a un repositorio público y activa GitHub Pages para enlace permanente.

3
